# 「跨境通途」线上演示操作说明

- 访问地址：<https://hsbc.mse.pub>（建议桌面版 Chrome 或 Edge）
- 演示账号：经办账号、复核账号各一个，账号和初始密码另行提供
- 演示材料：使用公开或合成材料

## 登录

1. 打开访问地址，输入账号、密码，点击 **登录**。
2. 首次登录会要求修改临时密码：当前密码填临时密码，新密码至少 12 位，点击 **保存并重新登录**，再用新密码登录。
3. 登录后进入工作台。切换账号：点击左下角姓名 → **退出登录**。

## 演示流程

**经办账号**

1. 左侧 **案件** → **新建案件**：勾选担保类型，上传材料，创建案件。
2. **02 提取审查**：等待文件解析完成，查看提取的字段；点击字段可在原件中定位，可查看中文参考译文、确认担保主体。
3. 点击 **开始预审**，在 **03 预审结果** 查看检查结果和邮件草稿，可导出 Excel。
4. 确认初审结果后点击 **完成初审并提交**，提交给复核人。

**复核账号**

5. 工作台 **待我复核** → 进入案件，核对后确认结束本轮，或填写原因退回。

**经办账号**

6. 复核确认后，在 **03 预审结果** 底部点击 **复核后完结**。
